# 听君讲江西

大一上学期《网页设计》期末作业 · 纯静态多页站点。

主题是江西的山、水、人和吃食。所有页面都是手写的 HTML + CSS，用 Dreamweaver 的思路搭：一张 1200px 定宽的大表格，顶上用 `<iframe>` 把 logo、导航栏、页脚拼进来，换页面的时候只换中间那块内容。

## 目录

```
index.html              首页「为什么一定要来江西」，十大理由
logo.html               页头（iframe 片段）
导航栏.html             四个频道的横条（iframe 片段）
版权信息.html           页脚（iframe 片段）
js/jquery-2.2.0.min.js  首页点击撒"富强民主"小字的特效依赖

山美/                   山：总览 + 三清山、庐山、龙虎山、井冈山、明月山、龟峰等
水美/                   水：鄱阳湖、仙女湖、庐山西海、陡水湖、龙源峡
人更美/                 人：陶渊明、欧阳修、王安石、晏殊、徐孺子
地道江西味/             吃：瓦罐汤、三杯鸡、粉蒸肉、藜蒿炒腊肉等
images/                 全站共用素材（LOGO、导航按钮、十大理由配图与视频）
```

## 技术说明

- 没有框架、没有构建步骤，双击 `index.html` 就能看。
- 各频道的二级页面放在 `频道名/` 下，右侧内容区用 `target="right"` 的 iframe 切换。
- 视频走原生 `<video>`，图片是 `<img>`，导航按钮的悬停换图用 Dreamweaver 那套 `MM_swapImage`。

## 响应式

原版是 1200px 定宽的表格布局，手机上要么横向滚动要么整页缩小成蚂蚁字。
现在加了一层不动结构的补丁，宽屏（>820px）版式和原来完全一样：

- `css/responsive.css`：给全部表格加 `max-width:100%`；小屏下把 `table/tr/td` 降级成普通块级元素往下排，首页四个频道按钮变成两行两列，频道页"左菜单 + 右内容"改成上下堆叠。
- `js/responsive.js`：只在小屏把 iframe 的高度改成内容实际高度（原来靠 6000px 的写死高度硬撑，宽度一收窄内容就被裁掉），iframe 里点链接换页后也会重新量。

已知短板：

- 正文是宋体小字 + 大图的老式排版，手机上就是"长图"式的阅读体验。
- `shanmei.html` 的跑马灯、`12.gif` 整页背景这些装饰在手机上没有单独优化。
